# MediaNotes API

Отдельный ASP.NET Core API, добавленный рядом с legacy-проектом MyVideo. Он не
меняет существующий сайт.

## Возможности

- регистрация и вход по email/паролю, JWT на 30 дней;
- синхронизация текущих заметок и изображений;
- SQLite в `App_Data/medianotes.db`;
- один снимок состояния в UTC-день, хранение 365 дней;
- одинаковое содержимое заметки хранится одной `NoteRevision`, а дневные снимки
  только ссылаются на неё;
- просмотр и точечное удаление дневных снимков.

## Запуск

```powershell
dotnet run --project MediaNotes.Api
```

Для серверов с ASP.NET Core Hosting Bundle задайте длинный случайный `Jwt__Key`
через переменную окружения и проксируйте `/medianotes-api` на этот процесс.
На текущем сервере `a.mosalski.de` используется совместимый проект
`MediaNotes.LegacyApi`, загружаемый существующим ASP.NET Framework сайтом.
